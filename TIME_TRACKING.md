## Tracking method

- The project owner starts or resumes a session by asking Codex to start or resume tracking.
- The project owner ends a session by asking Codex to pause or stop tracking.
- When a session ends, add its elapsed time to the log and update the current total.
- The current total includes completed sessions only; an open session is shown separately.
- Round completed sessions to the nearest minute.
- Codex cannot detect activity outside the conversation, so explicit start and stop messages define the tracked period.
