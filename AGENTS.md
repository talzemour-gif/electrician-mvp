## Project time tracking

`TIME_TRACKING.md` measures the project owner's time, not Codex work time. Start or resume a session only when the project owner asks to start or resume tracking. Pause or stop it only when requested, then add the elapsed session to the cumulative total. Do not automatically add time for implementation turns.
